# 🛍️ Teaching & E-Commerce Website

My first full-stack, fully functional **E-Commerce and Learning web application**, built with modern web technologies.

🚀 **Live Demo:** [teaching-website-roan.vercel.app](https://teaching-website-roan.vercel.app)

## ✨ Core Features

- **🔐 Advanced Authentication**: Secure login/signup flow powered by **Better Auth** with session and role management.
- **🛒 Shopping Cart & Checkout**: Complete logic for adding items, calculating totals, and processing orders.
- **📦 Product Management**: Dynamic product display with a fully functional **search feature**.
- **👤 User Dashboard**: A dedicated space for users to manage their profile and view order history (Mobile-Optimized).
- **🗄️ NoSQL Database**: Flexible data storage using **MongoDB** and **Mongoose** ODM.
- **📱 Fully Responsive**: Mobile-first design implemented with **Tailwind CSS**.

## 🛠️ Tech Stack

| Category | Technology | Details |
| :--- | :--- | :--- |
| **Framework** | Next.js 16 (App Router) | Leveraging Server Components and API Routes |
| **Language** | TypeScript | 56.3% of the codebase for type safety |
| **Database** | MongoDB / Mongoose | Schema-based data modeling |
| **Auth** | Better Auth | Modern and secure authentication library |
| **Styling** | Tailwind CSS / Shadcn/ui | Utility-first CSS with beautiful pre-built components |
| **Package Manager** | PNPM | Fast and efficient dependency management |
